# مشروع نظام الحضور الذكي للأندرويد

هذا **مشروع مصدر Android Studio** وليس ملف APK مبنيًا. يحتوي على نسخة البيانات JSON المرفقة داخل أصول التطبيق، ويُنسخ منها إلى التخزين الداخلي الخاص بالتطبيق عند التشغيل الأول.

## الوظائف الموجودة في النسخة الأولية
- واجهة عربية/كردية (يمكن التبديل من زر أعلى الشاشة).
- بيانات محلية على الهاتف فقط، بلا صلاحيات إنترنت.
- قائمة الطلاب مع البحث بالاسم أو الرقم، وإضافة طالب.
- تسجيل حضور/تأخير/غياب بعذر/غياب دون عذر بالبحث اليدوي.
- ملخص يومي وسجل آخر الحالات.
- قائمة تنبيه تعتمد على عدد سجلات الغياب دون عذر: 3 و5 و7.
- تصدير واستيراد نسخة احتياطية JSON من خلال منتقي ملفات أندرويد.

## بناء APK على الكمبيوتر
1. ثبّت Android Studio من الموقع الرسمي: https://developer.android.com/studio
2. فك ضغط ملف ZIP.
3. من Android Studio اختر **Open** وافتح مجلد `SmartAttendanceAndroid` (المجلد الذي يحتوي `settings.gradle`).
4. اسمح بمزامنة Gradle، وثبّت Android SDK Platform 35 عند الطلب.
5. من القائمة اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
6. عند اكتمال البناء اضغط **locate** من إشعار Android Studio. غالبًا ستجد الملف في `app/build/outputs/apk/debug/app-debug.apk`.

## التثبيت على هاتف أندرويد
1. انقل `app-debug.apk` إلى الهاتف عبر USB أو أي طريقة محلية.
2. افتح الملف من تطبيق الملفات.
3. إذا طُلب، اسمح لمصدر الملفات الذي تستخدمه بتثبيت تطبيقات غير معروفة.
4. اضغط تثبيت، ثم افتح **الحضور الذكي**.

## ملاحظات مهمة
- لم يتم بناء APK أو اختباره على جهاز فعلي هنا؛ المشروع يحتاج Android Studio/Gradle لبنائه.
- هذه نسخة أولية عملية. واجهة إدارة الصفوف والتحرير والحذف والتقارير المتقدمة غير مكتملة.
- عدّ الإنذارات الحالي يحسب سجلات الغياب دون عذر الموجودة، وليس أيام الغياب الفريدة؛ راجع السياسة المدرسية قبل الاعتماد عليه رسميًا.
- البيانات محلية خاصة بالتطبيق. حذف التطبيق قد يحذف بياناته؛ صدّر نسخة احتياطية بانتظام.
- ملف JSON الأصلي يحتوي بيانات شخصية للطلاب وأولياء الأمور؛ لا تشارك APK أو النسخة الاحتياطية علنًا.
